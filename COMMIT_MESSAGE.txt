## How It Works

### Automatic Flow
1. Admin approves booking in Equipment Rental Requests
2. System updates booking status to "approved"
3. `sendApprovalEmail()` is triggered
4. `BookingApprovedMail` generates PDF invoice from template
5. Email with PDF attachment sent to customer
6. Customer receives approval notification with invoice

### Manual Access
- Customer can visit `/bookings/{id}` to download/view invoice
- Direct URLs: `/invoices/{id}/download` or `/invoices/{id}/view`

## Configuration
- Update `.env` with mail settings (MAIL_DRIVER, SMTP credentials)
- DomPDF config automatically published to `config/dompdf.php`
- Invoice filename format: `Invoice-{order_number}.pdf`

## Security Notes
- PDFs generated on-demand (no file storage)
- Uses `findOrFail()` for validation
- Routes are public (consider adding auth middleware if needed)
- Email uses configured mail driver

## Performance
- PDF generation takes 2-5 seconds (first time)
- Consider queue for production (email job processing)
- No additional database queries required
